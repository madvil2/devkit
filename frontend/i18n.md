# i18n and typography

Applies to: all

- **I18N-1** Dictionaries:
  - strings live in `shared/i18n/locales/<lang>.ts`;
  - the base locale defines `Dict`; other locales are typed `Dict`, so a missing key fails typecheck;
  - namespaces per feature plus `common`, `errors`, `validation`, `meta`;
  - camelCase keys.
- **I18N-2** View hooks call `useT()`; JSX reads `t.ns.key`. Values go in via `format(template, params)` with `{placeholders}`. Never concatenate.
- **I18N-3** Plurals via `plural(count, forms)` on `Intl.PluralRules`. Dates and numbers only via `shared/lib/format`.
- **I18N-4** (i18n-remote) JSON per locale, loaded before first render, key type generated from the base JSON. A test checks key-set equality. Composed keys must exist in full.
- **I18N-5** Locale resolution:
  - (next) default locale unprefixed, others prefixed, `<html lang>`, hreflang + `x-default`;
  - (spa) stored → browser/Telegram language → default;
  - switching happens at runtime without reload.

## Typography

- **TXT-1** In every locale the project ships, non-breaking spaces bind: [rules: R-typography]
  - before a spaced em dash (`—`);
  - after `№` and `§`;
  - a number to its unit, and the locale's short words to the next word, from the locale's TXT-4 lists;
  - a number to the ordinary word it counts, and initials to each other and to the surname (review-enforced).
- **TXT-2** nbsp is written as the `\u00a0` escape (`\a0` in CSS strings). Literal U+00A0 is banned in source. nbsp is never used for spacing. [rules: R-literal-nbsp]
- **TXT-3** Designed line breaks are `\n` rendered by `Rich`; accents are `**`. Proofread headings for orphans.
- **TXT-4** Short-word and unit lists are per-locale data in `biome-plugins/typography/<lang>/R-typography.grit`. `biome.json` attaches the file to `src/shared/i18n/locales/<lang>.ts`; the dictionary file name is the locale, and a regional file such as `pt-BR.ts` is added to its language's entry. A unit binds to a number written as digits or as a `{placeholder}`. Seeded lists: [rules: R-typography]
  - ru short words (any case): в, во, и, к, с, со, у, о, об, на, за, по, до, из, от, не, ни, а, но, же, ли, бы;
  - ru units: км, м, см, мм, кг, г, т, л, мл, ч, мин, сек, с, ₽, руб., %, °, °C, °F;
  - en short words: `a`, `A`, `I`; articles and prepositions in headings and buttons are also bound (review-enforced);
  - en units: km, m, cm, mm, kg, g, lb, oz, l, ml, h, min, s, ms, %, °, °C, °F, AM, PM;
  - a unit followed by `²` or `³` (`м²`, `cm³`) binds the same way.
  - Adding a locale adds its lists and override in the same change, or an ADR stating the language binds no short words and no units. Nothing checks this; it is review-enforced. A dictionary with no lists gets only the universal TXT-1 checks.
